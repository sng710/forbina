# שער הנגב זוכרת — אתר ההנצחה

אתר הנצחה סטטי לזכר נופלות ונופלים מקהילות שער הנגב.

**אתר פעיל:** https://nocrueltyil.com/

## מבנה הפרויקט

- `index.html` — דף הבית ורשימת ההנצחה.
- `assets/js/person-page.js` — מנוע התצוגה המשותף לדפי ההנצחה האישיים.
- `assets/js/person-bootstrap.js` — טוען את נתוני האתר ואת מנוע הדף האישי לפי גרסת האתר.
- `people/` — דף אישי לכל אדם, בתיקייה נפרדת לפי מזהה.
- `assets/css/` — עיצוב משותף.
- `assets/js/` — נתוני האנשים ולוגיקת דף הבית.
- `assets/img/` — תמונות ונכסי תמונה.
- `assets/media/` ו-`assets/video/` — וידאו/מדיה מקומית.
- `tools/` — כלי בדיקה ותחזוקה.
- `docs/` — תיעוד, היסטוריית שינויים וארכיון QA/patches.

## עקרונות עבודה בטוחים

1. **Git הוא מקור האמת.** כל שינוי צריך להיות ניתן לצפייה כ-diff ולחזרה לאחור.
2. לפני שינוי בתוכן, תמונה או וידאו — יוצרים נקודת שחזור/commit.
3. משנים רק את הקבצים שנדרשים למשימה. אין לשלב refactor רחב עם שינוי תוכן.
4. לפני merge/deploy מריצים את כלי הבדיקה הקיימים ב-`tools/`, ובודקים ידנית דסקטופ ומובייל.
5. אין להוסיף לריפו התכתבויות פרטיות, פרטי קשר פרטיים, או חומר שמשפחה ביקשה להסיר מהפרסום.
6. תיקון או הסרה לבקשת משפחה מתועדים בתמצית בלבד — בלי לפרסם בריפו את תוכן הפנייה הפרטית.

## שינוי תוכן של אדם

- נתונים משותפים/אינדקס: בדקו את `assets/js/people.js`.
- דף אישי: `people/<id>/index.html`.
- תמונות: `assets/img/`.
- מדיה מקומית: `assets/media/` או הנתיב הקיים ברשומת האדם.

יש לשמור על מזהים, נתיבי קבצים וטקסטים קיימים שלא התבקשו להשתנות.
